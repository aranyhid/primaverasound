# Primavera Barcelona 2026 Personal Planner

A single-page, mobile-friendly festival planner for Primavera Sound Barcelona 2026.

## Files

- `index.html` - the complete website.
- `.nojekyll` - tells GitHub Pages to serve the static file directly.

## Upload to GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `README.md`, and `.nojekyll` to the repository root.
3. In GitHub, open `Settings > Pages`.
4. Set source to `Deploy from a branch`, choose your default branch, and select `/root`.
5. Save, then wait for GitHub to publish the public URL.

The site uses remote images and links from the official Primavera Sound website, so no extra asset folder is required.
